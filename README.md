# FitMongol media

Looping exercise demo clips for the FitMongol app, served through jsDelivr.
Licensed for use in FitMongol only; not for reuse or redistribution.

- `exercises/<slug>.mp4`: male model (or the only version)
- `exercises/<slug>_f.mp4`: female model

Clips are 480 px square, H.264 baseline, silent, faststart. Each app release pins a tag (v1, v2, ...).
